# 3D

## Conventions
- 1 unit = 1 m; Y up; right-handed. Cameras/nodes face −Z (`-global_basis.z`); imported models
  face +Z → `look_at(target, Vector3.UP, true)` (use_model_front) or `Vector3.MODEL_FRONT`.
- `global_*` and `look_at()` need the node in the tree (else use `look_at_from_position`).
- Gameplay rotation: basis/quaternion (`rotate_object_local`, `Quaternion.slerp`), not Euler
  `rotation` interpolation; `orthonormalized()` transforms you modify every frame.
- Keep scale same-signed and non-zero; CollisionObject3D scale uniform — scale child meshes,
  not manipulated nodes. `translate()` is not parent-space: use `position += offset`.

## Scene essentials
- The editor preview sun/environment are editor-only: add Camera3D (`current = true`),
  WorldEnvironment (one per tree) and lights yourself. Camera3D.environment overrides it.
- SpringArm3D third-person rig: Camera3D must be a direct child; exclude the player body.
- Physical light units require CameraAttributes on WorldEnvironment.

## Renderer feature matrix (check before using)
- Forward+ only: SSR, SSIL, SDFGI, VoxelGI, volumetric fog, TAA, FSR.
- Not Compatibility: decals, particle trails, Compositor, DOF, compute, SSR/SDFGI/VoxelGI, HDR.
- SSAO: Forward+ and Compatibility (4.6+), not Mobile. Mobile GI: LightmapGI + ReflectionProbe.
- Light limits — Forward+: 512 clustered elements/view; Mobile: 8 omni + 8 spot per mesh;
  Compatibility: 8 + 8 per mesh (adjustable); max 8 DirectionalLights.

## Lighting and shadows
- Raise Normal Bias before Bias; always set directional shadow Max Distance; disable shadows on
  small/distant omni/spot lights; use Distance Fade. `cull_mask` doesn't stop shadow casting.
- AreaLight3D only for high-end/cinematic targets. Light Bake Mode Disabled (not hidden) to
  exclude from lightmaps.
- GI choice: desktop dynamic → SDFGI; baked → LightmapGI (needs UV2, editor bake, bakes only its
  siblings/children); mobile → LightmapGI + ReflectionProbe; VoxelGI needs walls ≥1 voxel thick.
  GI mode Static for level geometry, Disabled for small dynamic objects.

## Materials and transparency
- Precedence: `material_override` > surface override > mesh material; `material_overlay` on top.
- Foliage: Alpha Scissor; hair: Alpha Hash; Depth Pre-Pass for semi-transparent surfaces.
  Alpha blending casts no shadows and sorts by origin; non-Mix blend, refraction or Pixel Alpha
  fade force blending (prefer Dither fade).
- Normal maps are OpenGL (Y+); convert DirectX maps with Normal Map Invert Y.
- Z-fighting: raise Camera3D `near`. Per-instance variation: `instance uniform` +
  `set_instance_shader_parameter`, not material duplication.

## Particles
- GPUParticles3D needs a process material AND a draw pass mesh (`draw_pass_1` is null by default);
  Vertex Color → Use As Albedo for particle colors; billboard via the draw material.
- They ignore physics bodies (use GPUParticlesCollision* nodes); outside the visibility AABB
  there's no rendering or collision.

## Performance features
- Mesh LOD auto-generated for imported scenes (tune `lod_bias`); HLOD with visibility ranges +
  `visibility_parent`; occlusion culling = project setting + baked OccluderInstance3D (opaque
  MeshInstance3D only; toggle visibility instead of moving occluders).
- Many identical meshes: MultiMeshInstance3D (set `transform_format` before `instance_count`).
- CSG is for prototyping: bake to mesh + StaticBody collision before shipping.

## Model import
- Prefer glTF 2.0 (`.glb`). `.blend` needs Blender on every machine; FBX via ufbx; OBJ has no
  animation/skeleton; avoid DAE for animation.
- Before export: apply transforms, triangulate, reset to rest pose, metric scale; enable
  backface culling in Blender or materials import double-sided.
- Node name suffixes: `-col`, `-convcol`, `-colonly`, `-convcolonly`, `-navmesh`, `-occ`,
  `-rigid`, `-noimp`; animations named `*loop`/`*cycle` loop.
- Customize via Advanced Import Settings (extract materials to `.tres`, generate collision),
  an inherited scene, or an `@tool` EditorScenePostImport script. Primitive collision for
  dynamic bodies; trimesh only for static geometry.
- Wrap imported models in your own scene (root + model instance + AnimationTree/colliders);
  don't edit the imported scene directly (reimport overwrites it).
- Retarget humanoids with BoneMap + SkeletonProfileHumanoid (T-pose facing +Z).
