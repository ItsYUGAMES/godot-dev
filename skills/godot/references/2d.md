# 2D

## Coordinates, drawing order, cameras
- +Y is down; angles in radians (`rotation_degrees` for degrees); `transform.x` is local right.
- Draw order: tree order (later draws on top), then `z_index` (drawing only — not input or
  processing). HUD/backgrounds in CanvasLayers (layer 1 default; z never crosses layers).
- Scroll with Camera2D (first enabled camera becomes current; `make_current()` needs enabled);
  real view position = `get_screen_center_position()`. Don't move the world.
- Transform/modulate/visibility propagate only through CanvasItem parents; a plain Node between
  them breaks the chain.
- Convert input to local space with `make_input_local()`/`get_global_mouse_position()`; screen
  position = `get_viewport().get_screen_transform() * get_global_transform_with_canvas() * p`.

## TileMaps (TileMapLayer only — TileMap is deprecated)
- One TileMapLayer node per layer, sharing an external TileSet `.tres`.
- In the TileSet: set tile size before auto-creating atlas tiles; add Physics/Navigation/
  Occlusion/custom-data layers before drawing per-tile polygons; terrain set IDs start at 0.
- Code: `set_cell(coords, source_id, atlas_coords, alternative)` with explicit IDs;
  empty cell → `get_cell_source_id(c) == -1`; `local_to_map(to_local(global_pos))`.
- Changes apply at frame end; `update_internals()` forces it (expensive). Don't mutate shared
  TileData at runtime (use `_tile_data_runtime_update` or duplicate).
- Prefer rotate/flip while painting over alternative tiles; avoid scene-collection tiles unless
  needed (one instance per cell). Bake navigation into a NavigationRegion2D.
- Tile data is a base64 `tile_map_data` blob in `.tscn` (format=4): edit tiles via editor/
  godot-ai `tilemap_manage`, never by hand.

## Parallax (Parallax2D — not ParallaxBackground/ParallaxLayer)
- Child textures top-left at (0,0); `repeat_size` = texture size (texture ≥ viewport);
  raise `repeat_times` when zooming out; `repeat_size` ignores scale.

## Sprites and animation
- AnimatedSprite2D + SpriteFrames for frame-only animation; Sprite2D `hframes/vframes` +
  AnimationPlayer when other properties animate too. `play()` applies next frame — call
  `advance(0)` when the pose must show now.
- Large transparent sprites: MeshInstance2D (less overdraw).

## Custom drawing
- `draw_*` only inside `_draw()`; call `queue_redraw()` when its inputs change (output cached).
- Don't pass textures/styleboxes held only in locals to `draw_*` (freed before rendering).
- Odd line widths: offset by 0.5 px; `antialiased = true` on Line2D/draw calls.

## Lights and shadows
- CanvasModulate for ambient; PointLight2D (texture) / DirectionalLight2D; LightOccluder2D or
  TileSet occlusion for shadows. The clear color is never lit.
- Lighting runs at viewport resolution; pixel art needs snapping in shaders. Prefer additive
  CanvasItemMaterial sprites over many short-lived lights.

## Particles
- GPUParticles2D + ParticleProcessMaterial; flipbooks need CanvasItemMaterial with Particle
  Animation and H/V frames; generate a visibility rect; 2D GPU particles don't collide with
  bodies (use collision nodes) and `emit_particle()` doesn't work on Compatibility.
- Retrigger one-shots with `restart()`; vary density via `amount_ratio` (changing `amount`
  restarts).

## Pixel art checklist
Stretch `viewport` + integer scale (see `project-setup.md`); default texture filter Nearest
(set on CanvasItem/project, not in the import dock); import Lossless, no VRAM compression, no
mipmaps; fonts Nearest with subpixel positioning off; snap camera to pixels.

## Rendering 2D
- HDR 2D (`rendering/viewport/hdr_2d`) for selective glow; canvas samplers then need
  `source_color`. MSAA 2D is separate from 3D and absent in Compatibility.
- Split screen: share `world_2d` between SubViewports; `camera.custom_viewport` + `make_current()`.
